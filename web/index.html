Verdict

-

Heuristic analysis. A clean result does not guarantee an email is safe, and a flagged one is not proof of malice. When in doubt, contact the sender through a channel you already trust.

What gets checked

Sender

SPF, DKIM and DMARC results, spoofed display names, lookalike and homograph domains, Reply-To and Return-Path mismatches, the relay path and the originating IP.

Links

Link text that shows a different site than the real target, raw-IP and punycode URLs, brand impersonation, shorteners, free-hosting abuse, and hidden redirects. Safe Links and URL Defense wrappers are unwrapped first.

Attachments

Executables and double extensions, files whose content doesn't match their type, macros, remote templates, PDF JavaScript, HTML smuggling, and encrypted or nested archives. Files are only read, never opened or run.

Content

Urgency and threat language, credential requests, payment and gift-card lures, inline login forms, QR-code phishing hints, and zero-width-character filter evasion.

How to export an email (.eml)

  • Gmail: open the message → ⋮ (More) → Download message.
  • Outlook on the web / new Outlook: open the message → … → Save as or Download (.eml).
  • Classic Outlook (desktop): saves .msg, which isn't supported. Open the message, then File → Properties, copy the Internet headers, and paste them above (headers-only check), or forward the mail as an attachment from Outlook on the web.
  • Apple Mail: select the message → File → Save As… → Format: Raw Message Source.
  • Thunderbird: select the message → File → Save As → File.

Prefer the command line? The same engine is available as a Python CLI with VirusTotal lookups and JSON output. See the GitHub repository.
